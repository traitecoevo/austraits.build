README Pollinators data

The excel workbook contains the data from both the field and lab notes. The metadata tab in the workbook explains this data in depth. 
Briefly, this workbook contains the following data and information:

Floral visitors ALL_publishing.xlsx 
	this excel contains all of the raw data from the field and lab in the "Floral visitors_ALL" main data tab locked sheets.
	A duplicate of this tab "Floral visitors_ALL duplicate" has the same data and was used to generate the subsequent sheets:
	
	"Fig 2 data" - This is a subset of "Floral visitors_ALL" which only includes the species which we assessed the foraging behavior. This was used to create:
	"Fig 2 calculations" - Pivot table to calculate the proportion of each foraging behaviour that we observed. Values were used to create Figure 2
datasheet: "Behaviours" - A summary of the above sheets by species to quickly check for what morphospecies we observed which behavior for discussion in text
datasheet: "Table 1: Lindsey" Table 1 in text. Created based from a summary of "Floral visitors_ALL" data and the visitation frequencies calculated in R. The script and R calculations are provided in the sheet: "visitorfrequency_Rcalculation"


The .csv attachments contain a single worksheet from the excel file which was used in R.
The R script and calculations are provided in the .html file.
